# MotionSites Free Prompt Library

A searchable, developer-friendly collection of **253 website and UI generation prompts**. This README organizes every prompt by its best-fit business niche while retaining the prompt's functional format, practical use cases, and a direct link to the usable prompt file.

> [!IMPORTANT]
> The archive contains **89 original prompts** captured from the source endpoint and **164 clearly labeled reconstructions** created from public metadata and preview references. A reconstruction is useful as a working build brief, but it is not the original paid prompt text.

## What is included

- 253 ready-to-inspect prompt briefs
- Direct GitHub links to every `working-prompt.md` file
- Business-niche categories for faster discovery
- Format labels such as hero, landing page, pricing, dashboard, CTA, and content section
- Use-case guidance for adapting each design to a real client or product
- A React/Vite catalog app with search, filters, previews, and copy actions

## How to use the library

1. Choose a niche below.
2. Select a prompt based on its description, format, and use cases.
3. Open the linked prompt file and copy the content under **Prompt** or **Reconstructed Working Prompt**.
4. Replace the sample brand, copy, colors, media, and metrics with verified project content.
5. Paste the adapted prompt into your coding agent or AI website builder, then review responsiveness, accessibility, asset rights, and production behavior.

## Run the visual catalog locally

```bash
npm install
npm run generate:catalog
npm run dev
```

Open [http://127.0.0.1:5173](http://127.0.0.1:5173).

### Useful commands

```bash
npm run build
npm run lint
npm run test -- --run
npm run test:e2e
npm run generate:catalog
node scripts/build-readme.mjs
```

The catalog generator reads `liro-prompts/*/metadata.json` and `working-prompt.md`, then updates the app data. The README generator rebuilds this categorized directory from those same source files.
